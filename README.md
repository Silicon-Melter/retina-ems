# RETINA EMS (built site)

The RETINA EMS demo apps (EMS 1669 Call Intake, Dispatch, Ambulance Copilot), built from a private repository and
published with GitHub Pages. Anyone can open the page; case data needs a sign-in to the RETINA EMS server
(https://retina-hub.tailb3f692.ts.net/ems). Demo data only: patients are fictional.
